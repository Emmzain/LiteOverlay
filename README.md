# LiteOverlay ⚡

> **Ultra Low-End Gaming Performance HUD & Hardware System Monitor for Low-End PCs & Laptops**

LiteOverlay is a lightweight gaming HUD dashboard and standalone native Windows overlay application designed specifically for low-end PCs and laptops. It consumes **under 15 MB RAM** and **0% CPU** overhead during gameplay.

---

## 🌟 Key Features

- **🎮 Floating Borderless Gaming HUD**: Real-time per-pixel transparent overlay for Live FPS, Network Ping, RAM, CPU Usage, GPU Usage, Thermal Temp, Battery %, Network Speed, and Storage.
- **🎨 Custom HUD Styling**: Full control over background opacity sliders, font sizes, corner rounding radius, accent color themes, and border line/glow toggles.
- **⚡ Super Low RAM Footprint**: Optimized native Windows C# executable (`LiteOverlay.exe`) and installer (`SetupLiteOverlay.exe`).
- **🌐 Web Dashboard & Vercel Support**: Ready for 1-click zero-config deployment on Vercel or any static web host.

---

## 🚀 Live Web Dashboard Deployment (Vercel)

You can host and deploy LiteOverlay directly on Vercel:

1. Import this repository into **[Vercel](https://vercel.com)**.
2. Vercel automatically detects `index.html` and static assets.
3. Your web dashboard and download links for `SetupLiteOverlay.exe` will be live instantly!

---

## 🛠️ Building Executables Locally

To compile the native Windows executables (`LiteOverlay.exe` and `SetupLiteOverlay.exe` installer):

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
